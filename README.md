# Java Learning Process

A collection of small Java exercises documenting my learning progress and programming skills.

## Exercises

| Directory | Topic |
| --- | --- |
| [`variables`](./variables) | Java variables and basic output |
| [`acceptingData`](./acceptingData) | Reading user input |
| [`ageVerificationSimple`](./ageVerificationSimple) | Conditional logic and age verification |
| [`bodyMassCalculator`](./bodyMassCalculator) | BMI calculations and user input |
| [`shoppingAssistance`](./shoppingAssistance) | A simple shopping assistance program |
| [`oopInsight`](./oopInsight) | Introductory object-oriented programming |
| [`russianRullet`](./russianRullet) | A small Java exercise (spelling preserved to match the project folder) |

## Requirements

- Java Development Kit (JDK) 8 or newer

## Running a Project

Each exercise is a standalone IntelliJ IDEA project. To run one from a terminal:

```bash
cd <exercise-directory>/src
javac Main.java
java Main
```

For example:

```bash
cd variables/src
javac Main.java
java Main
```

You can also open each exercise directory as a project in IntelliJ IDEA and run `Main.java` from the IDE.
